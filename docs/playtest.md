## 日志解释

- direct_damage：第一轮确定伤害。
- total_damage / rounds：整个操作伤害和结算轮数。
- deterministic_matches：每轮收缩后、补猫前已有的有效线数量。
- random_matches：补猫后出现、其完整格集合不在补猫前匹配列表中的线；包括被随机新猫延长的原有线，不能直接解释为“全部由运气造成的伤害”。
- opponent_best：换手后所有合法交换中最大的第一轮确定伤害，不是最优长期策略。
- start / end：规则状态和RNG状态，供诊断。

## 已知边界

- 固定多轴收缩优先级可能不够直观，需要通过复杂交叉局面获取反馈。
- 100HP、四色、伤害参数尚未进行真人平衡测试。
- 补猫不会直接制造三连；收缩仍可能产生连锁，设置了100轮异常保护。
- 原型使用程序化美术，无音效；飞散猫只是特效。
- 本地测试包未做发行签名和公证，目标是当前macOS机器上的验证。
- 没有AI、联网、跨平台验收或持久化存档；调试可在本次会话恢复上一回合。
