# 后续玩法演进与肉鸽方向（未实现）

> 本文档记录从当前双人原型（规则 v2）向**单人肉鸽（PvE）**演进的核心思路与待细化方向，用于后续逐项拆解与验证；当前已实现规则仍以 [rules.md](rules.md) 为准。

## 1. 核心定位转变

- **从本地双人 PvP 转向单人肉鸽 PvE**：保留“共用六边形棋盘”的攻防一体核心骨架，将对手替换为各具性格与机制的**猫咪 Boss**，面向微信小游戏打造“3 秒上手、易触发大爆炸、中后期有博弈深度”的轻策略肉鸽体验。
- **核心情绪目标**：**操作极简 + 满屏炸裂爽感 + 局势博弈张力 + 猫梗趣味性**。

## 2. 已确认的 4 项核心设计方向

### 2.1 降低找消门槛：分层微动提示
- 目标：不靠“找哪三个能消”为难玩家，把注意力留给“选哪一步更赚/更安全”。
- **分层提示（避免全屏晃动造成视觉噪音）**：
  - 常态微动/高亮：仅提示**高价值交互**（能直接引爆大猫、4 连/V 字高收益、或 Boss 盯上的危险格）。
  - 兜底提示：普通 3 连小猫平时保持安静，玩家停顿数秒未操作时再轻晃 1~2 组。

### 2.2 放开爽感上限：连锁二次引爆
- 打破规则 v2 中“被射线波及的大猫不二次自爆”的限制，**放开大猫被射线波及时的连锁二次引爆**。
- 强化爆炸视觉表现（多米诺式连环引爆、炸裂粒子、节奏停顿/震屏反馈），把“攒雷 → 一键清场”打造成核心多巴胺来源。

### 2.3 化解防守焦虑：机制型猫梗 Boss + 意图透明
- 共用棋盘的“合成即埋雷”天然伴随防守焦虑（担心刚合的大猫被对手抢先引爆）。
- **不做“高智商通用 AI”**（太笨没博弈，太聪明极度劝退），改为**有固定习性、可预测、可利用的机制型猫梗 Boss**：
  - 结合猫梗塑造关卡特色（如大橘贪吃特定色、奶牛猫周期发癫打乱局部、高冷布偶偏好边缘等）。
  - 引入**清晰意图预告**（如标出 Boss 下回合目标或行动节奏/CD），让玩家既有“拆招/设陷阱”的博弈感，也有安全发力引爆的爽感窗口。

### 2.4 肉鸽构筑（Build）：改写机制而非纯堆数值
- 肉鸽变数用来丰富博弈维度与爽感流派，避免无聊的纯加攻加血，优先围绕三大底层机制做**机制型词条/遗物/特殊猫**：
  - **爆发流（改射线）**：连锁引爆增伤、射线边界反弹、射线变范围爆破等。
  - **合成流（改升级）**：合成大猫叠护盾、4 连出更高级“猫王”、大猫存活蓄力增伤（养蛊拆弹）等。
  - **收缩流（改控盘）**：按收缩位移量增伤、固定某只猫参与收缩、暂缓爆发或改变收缩顺序等。
  - **跨色/特殊猫种**：跨色合成三花、奶牛等特殊猫（需保证条件清晰可预览）。

## 3. 最小验证路径（MVP 顺序）

先验证核心循环是否上头，再逐步扩充内容量（不将额外随机性当作策略深度）：

1. **第一步（手感与爽感）**：验证“分层微动提示” + “大猫连锁二次引爆”的规则与炸裂特效。
2. **第二步（核心 PvE 博弈）**：将 P2 替换为第 1 个“有性格 + 明意图”的猫梗 Boss，验证“埋雷 vs 防反打”的单人博弈体验。
3. **第三步（肉鸽循环）**：接入局间 3 选 1 机制型构筑与多关卡猫梗 Boss 梯队。
